
# OpenBOR-Base64E

Custom Android launcher based on DCurrent/OpenBOR.

## Features
- Russian, Kazakh and English menu
- Start game button
- port by base64E credit
- Touch control size and opacity settings
- Android arm64-v8a APK build via GitHub Actions

## Add a game
Place a legally distributable `.pak` file in `assets/`.

## Build
Open the Actions tab and run `Build Base64E OpenBOR APK`.
Download the APK from the workflow artifacts.

Upstream: https://github.com/DCurrent/openbor
